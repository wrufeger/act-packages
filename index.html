act packages

Packages for the agentic coding template. Fetch one with packages.py fetch <id>, then read the plan from packages.py add <id> before you say yes.

Packages from the next template release. The package layer (packages.py, /act-packages) is in no release of the template yet: v2.6.0 and older do not have it. It comes with the next release. Until then a project needs the update channel latest: set update-channel: latest in docs/ai/config.md and run act-update.

homenet 0.1.0

Rules, roles and skills for running a home network or homelab from a project on the template: LAN and WLAN, router and network controller, hypervisor, Raspberry Pi and other servers, DNS filter, devices, firewall and Home Assistant. The package carries no network data (no addresses, host names or credentials); the setup records them in the project under `docs/project/homenet/`. It builds on `R-safe-approval` and `.act/rules/topics/live-systems.md` and repeats neither. - Rules: `R-homenet-access` (a rights table per system and way; a dated entry there is the standing approval for a named action class), `R-homenet-never` (the hard core no standing approval covers), `R-homenet-ssh`, `R-homenet-rename`, `R-homenet-names`, `R-homenet-exports`, `R-homenet-handoff`; an extension of `R-safe-approval` that points to the rights table. - Roles: `homenet-reader` (reads only, never scans, cross-checks every write over its own way) and `homenet-writer` (backs up first, never deletes, a write is done only after the reader's cross-check). - Skills: `homenet-inventory` (first inventory and doc audit against the live state) and `homenet-add-device`. - Topic: `homenet-mcp` (MCP servers and APIs for Home Assistant, network controller, hypervisor, monitoring and NAS, with read and write kept apart). - Code: `install.py` only reports which tools are there (`ssh`, Python, interpreter traps on Windows); it opens no connection and writes nothing. The check module `homenet_no_scan` refuses port scanners (`nmap`, `masscan`, `zmap` and similar, `nc -z` over more than one port) in shell calls of Claude Code.
