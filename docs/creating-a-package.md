# Creating a package

A package is a folder under `packages/<id>/`. The template reads it with `python .act/scripts/packages.py plan <folder>`,
which checks it and prints what installing it would do; it writes nothing and runs no package code. Start from
`packages/example/`.

The full guide to creating, checking and submitting a package is on the documentation site, in English and German:
<https://wrufeger.github.io/agentic-coding-template-docs/guides/packages/>.

The package format, field by field: <https://wrufeger.github.io/agentic-coding-template-docs/reference/package-format/>.
